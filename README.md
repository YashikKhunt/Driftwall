# Driftwall

A free, independent macOS live wallpaper app, built with SwiftUI, AppKit, Metal, and AVFoundation. No accounts, subscriptions, network services, or third-party dependencies.

## Run

Open `build/Driftwall.app`. Driftwall starts quietly with only a menu-bar icon: it has no Dock icon or automatic library window. Choose **Open Library** from its mountain icon, pick a scene, and click **Set wallpaper**. Closing the library keeps your wallpaper running. The menu also provides pause, restore, launch at login, and quit controls.

To install, drag `Driftwall.app` into Applications. Enable **Launch at Login** in the menu after moving it to its permanent location. At login, Driftwall resumes your saved wallpaper without opening the library. This local build is ad-hoc signed, not notarized for public distribution.

## Features

- 16 original animated scenes across Nature, Ocean, Space, Abstract, and Minimal collections.
- Library tab with category and search filters, alongside the featured Discover view and My videos.
- Import locally playable MP4, MOV, and other movie files. Videos are copied into your own library, muted, and looped with AVPlayerLooper.
- Desktop windows stay behind icons, ignore clicks, and follow desktop Spaces.
- Apply to all displays or the primary display; reconnecting displays rebuilds playback.
- Pause/resume and restore the original desktop without changing the system wallpaper.
- Pause on battery power, screen sleep, inactive user session, serious thermal pressure, and best-effort full-screen detection.
- Saved wallpaper and preferences, plus optional launch at login.
- Adjustable 15/30/60 fps for generated scenes. Rendering is capped at 1920 logical pixels wide to reduce GPU work; video resolution is preserved and cropped to fill the display.

## Build and verify

Requires macOS 14 or newer and Apple's Command Line Tools (`xcode-select --install`).

```sh
bash scripts/build.sh
bash scripts/test.sh
```

The smoke test compiles the actual Metal shader, renders all 16 scenes on the GPU, checks image variation, and verifies their frames change over time.

## Scope and limitations

Driftwall is an independent implementation inspired by the live wallpaper category. It does not include MacWall code, branding, or its wallpaper catalog. All bundled scenes are generated by original shaders.

This version animates the desktop using noninteractive desktop-level windows. It does not integrate with macOS Lock Screen or screen savers. Mission Control, Show Desktop, Stage Manager, and full-screen Spaces may arrange these windows differently across macOS versions. Full-screen pausing uses visible window dimensions, is global across displays, and is best effort. No Screen Recording or Accessibility permission is requested.

Energy use depends on resolution, frame rate, hardware, and video encoding; no specific CPU or battery savings are promised. The original scene previews are stills so browsing does not run multiple animations. Imported videos can be previewed with their playback controls.

Video copies and metadata live in `~/Library/Application Support/Driftwall/Library`. Removing a video deletes only the imported copy, never the source file. Preferences are stored in the `local.driftwall.app` defaults domain. Quitting removes every desktop window and restores the visible system wallpaper.
